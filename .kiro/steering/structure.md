# Repository structure

```
apps/
  mcp-server/          ShopVoice MCP server (port 8090)
    src/config.ts      env → McpServerConfig
    src/http.ts        /mcp, /healthz, /readyz, auth, Origin check, rate limits, write-scope gate
    src/client-ip.ts   client address behind a proxy (X-Forwarded-For)
    src/store.ts       ShopStore interface; pg-store.ts (Postgres + RLS), memory-store.ts (offline demo)
    src/tools.ts       MCP tools (voice-first, ≤35 words)
  alexa-sim/           Alexa+ simulator (port 8091)
    src/server.ts      /, /static/*, /healthz, /readyz, /api/config, /api/turn, /api/tts, /api/reset
    src/agent.ts       turn loop; holds confirmation tokens; gates confirm_reorder on a spoken "yes"
    src/brain.ts       Brain interface, RulesBrain (offline); claude-brain.ts (Anthropic API)
    src/toolbox.ts     MCP client over Streamable HTTP
    static/            index.html, app.js, styles.css (no framework, strict CSP: no inline script/style)
  gateway/ admin/ worker/ miniapp/   pre-existing invoice pipeline; do not change for the hosted demo
packages/common/       shared library (pg pool, runTenantScopedTransaction, logger, rate limiter)
db/v2/migrations/      NNN_v2_<name>.sql; next free number is 019
db/v2/seed/            001_dev_seed.sql, 002_demo_shop_seed.sql (generated by scripts/v2/gen_demo_seed.mjs)
scripts/v2/            migrate / seed / token tools (db_v2_lib.mjs, remote_migrate.mjs, mcp_token_lib.mjs)
scripts/deploy/        NEW: Render deploy helpers (db_prepare.mjs, reseed_demo.mjs)
scripts/demo/          e2e_voice_flow.mjs (5 demo utterances), inspector_evidence.mjs, latency_probe.mjs
tests/v2/              unit tests; tests/v2/db/ Postgres tests
docs/hackathon/        submission docs; DEPLOY_RENDER.md is NEW
infra/aws/             implemented, not deployed (AWS account unavailable); do not modify
render.yaml            NEW: Render Blueprint at the repo root
```

## Naming

- Files are kebab-case `.ts` in apps and `.mjs` for scripts and tests.
- Environment variables are prefixed per app: `MCP_*` for the MCP server, `SIM_*` for the simulator, `DEMO_*` for demo data.
- Test names describe the behaviour: `test('read-only token cannot call confirm_reorder', …)`.
