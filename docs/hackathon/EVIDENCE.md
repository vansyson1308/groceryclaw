# ShopVoice: evidence index

One place for judges to check each claim. Everything here was produced by commands in this repo, and each row says how to reproduce it.

**The live path is:** voice → simulator (Claude) → MCP Streamable HTTP → MCP server → Postgres with RLS, on Render. **No AWS service runs:** the account was locked (BLOCKERS B7). Rows 6 and 7 show AWS code that is *implemented, not deployed: AWS account unavailable*.
