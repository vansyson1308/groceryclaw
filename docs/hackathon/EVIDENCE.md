# ShopVoice: evidence index

One place for judges to check each claim. Everything here was produced by commands in this repo, and each row says how to reproduce it.

**Not yet shown here:** anything that needs a live AWS account. The cloud deploy, the Bedrock agent answering live, Polly voices, and latency over the internet are all blocked on credentials (BLOCKERS.md B2). The AWS code paths are built and tested with fakes, and the CDK stack synthesizes; see rows 6 and 7.
